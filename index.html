    ⚙️ Firebase Setup Instructions

    Step 1 — Go to console.firebase.google.com and sign in with Google.
    Step 2 — Click Add project, name it, skip Analytics, click Create.
    Step 3 — Click the </> Web icon, give it a nickname, click Register app.
    Step 4 — Copy the firebaseConfig values shown.
    Step 5 — Open this HTML file in a text editor, find PASTE YOUR FIREBASE CONFIG HERE and replace all six YOUR_... values.
    Step 6 — Go to Firestore Database → Create database → Start in test mode → pick any region → Done.
    Step 7 — Save and open the file. Done!
