    How Firebase Sync Works

    All calendar data is stored in Firebase Firestore — a free, real-time cloud database. Changes from either parent appear on the other's screen within 1–3 seconds. Your data is identified only by the join code — no accounts or passwords needed.

    ⚙️ Firebase Setup Instructions

    Step 1 — Go to console.firebase.google.com and sign in with a Google account.
    Step 2 — Click Add project, give it a name (e.g. "our-calendar"), skip Analytics, click Create project.
    Step 3 — Inside your project, click the </> (Web) icon to add a web app. Give it a nickname and click Register app.
    Step 4 — Firebase shows you a firebaseConfig object. Copy all 6 values.
    Step 5 — Open this HTML file in a text editor. Find the block labelled PASTE YOUR FIREBASE CONFIG HERE and replace each YOUR_... placeholder.
    Step 6 — In Firebase console, go to Firestore Database → Create database → choose Start in test mode → pick any region → Done.
    Step 7 — Save the file and open it in your browser. Done!
